# Portfolio Hero — Astro

The same portfolio hero section that was built in Elementor, rebuilt in
Astro. Dark navy background, pink accent, the user's own photo on the
right, and the user's own name and work on the left.

## Run it

```bash
npm install
npm run dev
```

Then open the address the terminal shows, usually
http://localhost:4321/

## Build it

```bash
npm run build
```

## Photo note

The hero photo lives at `public/images/portrait.png`. The GitHub
connector used for the first push only accepts text files, so a binary
image cannot travel through that push. Upload `portrait.png` to
`public/images/` on GitHub (web upload) if the image is missing there.
